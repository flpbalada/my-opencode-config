# OpenCode Configuration

Personal [OpenCode](https://opencode.ai/docs) configuration: agent instructions, custom workflows, tools, integrations, and UI preferences.

Before OpenCode existed, I maintained a personal "second brain": notes on programming patterns, product management frameworks, and psychology principles. I turned these notes into skills the AI can execute, making that knowledge actionable during coding sessions.

Feel free to:

- Browse and adapt skills for your own config
- Use agents as templates for your workflows
- Share tips and tricks you've found useful

## Skills Library

Skills are **executable knowledge notes**: my personal "second brain" converted into actionable guidance for the AI agent.

The full skills library lives in [`flpbalada/fb-skills`](https://github.com/flpbalada/fb-skills).
